## 프로젝트 소개

‘뚜(TTU)’는 기혼 주선자가 친구의 소개를 돕는 연결망을 중심으로 설계한 서비스다. 주선자는 소개할 지인을 초대하고 다른 기혼 주선자와 **개별 협력**하며, 한 번에 처리할 다음 행동과 결과를 확인한다. 한 싱글은 **여러 주선자와 독립적으로 연결·해제**할 수 있다. 싱글은 주선자를 기다리는 것 외에도 제한된 익명 후보를 살펴보거나 **원하는 스타일을 선택한 주선자 한 명에게 비공개로 요청**할 수 있다.

소개가 성립하려면 **주선자들의 제안 검토 → 양쪽 싱글의 각각의 소개 수락 → 각자의 최종 연락처 등 정보공개 승인 → 주선자의 실제 연결 확인**이 필요하다. 넛지나 관심 표시만으로 상대에게 메시지가 전달되거나 소개가 성립하지 않는다. AI 추천·설명은 후속 보조 기능이며 주선자와 당사자의 판단·동의를 대체하지 않는다.

## 기본 이용 흐름

1. **기혼 주선자 참여:** 주선자가 직접 신청·승인 절차를 거쳐 지인 싱글에게 초대를 보낸다. 지인의 개인정보를 대신 입력하거나 동의 없이 공개하지 않는다.
2. **싱글 본인 가입·관계 승인:** 싱글은 직접 동의하고 하나 이상의 주선자와 각각 연결한다. 공개 설정은 기본 **L0 비공개·미동의**다. L1(연결망 공개)을 추천하되 사용자가 직접 선택해야 한다.
3. **싱글의 능동적 요청:** 본인이 승인한 주선자 연결망 안에서 허용된 익명 카드만 발견하거나, 카드가 0명이어도 **‘원하는 스타일 알려주기’** 요청을 지정 주선자 한 명에게 전달한다. 본인이 L0를 유지해도 넛지 요청은 가능하다.
4. **주선자 간 협력·검토:** 기혼 주선자 A/B는 협력 요청을 수락한 뒤 각자 관리하는 싱글을 지명한다. 상대 주선자의 **전체 지인 목록은 열람하지 않고**, 당사자가 허용한 요약만 공유한다.
5. **양측 소개 수락·정보공개 승인:** 싱글 두 명이 각각 소개를 수락하더라도 실명·사진·연락처 등 추가 정보는 **각자 최종 동의한 범위에서만** 공유한다. 거절·철회는 존중한다.
6. **실제 연결·결과 확인:** 주선자가 메신저 등 앱 밖에서 연결을 도울 수 있으며, 실제 연결 확인 후에만 소개 완료로 기록한다. 양측 수락과 실제 연결·첫 만남은 별도 상태다.

## 현재 검증 범위

**11월 7일 모바일 웹 베타를 목표로** ‘주선자 협력 → 양측 싱글 동의 → 실제 연결’의 작은 완결 여정과 ‘싱글 스타일 요청 → 주선자 검토’의 작은 여정을 우선 검증한다. **정식 출시나 사용자 모집 결과가 이미 확인됐다는 뜻은 아니다.** 실제 주선자 확보·재활동, 초대→싱글 본인 동의, 양측 수락, 사용자의 공개 수준 이해를 실제 행동과 인터뷰로 관찰한다.

- **정보공개 3단계:** L0 비공개(기본·미동의), L1 승인 주선자 연결망 내 비식별 카드(명시동의), L2 장래 더 넓은 공개 희망(별도 선택). **11/7 베타에서 L2를 선택하더라도 실제 발견 범위는 L1과 동일한 D14=A 한도를 유지**하며, 확대 시 새 동의가 필요하다. 공개 수준과 실제 보여주는 정보 항목, 제안 수락·연락처 공유 동의는 각각 별도다.
- **P0 핵심:** 기혼 주선자 승인·싱글 본인 동의, 복수 주선자 연결, 동의·공개 통제, 주선자 협력·제안, 양측 수락·연결 확인, 싱글 스타일 요청, 철회·신고 등 안전 절차.
- **조건부:** 실제 동의·접근 검사를 통과한 비식별 후보 카드와 카드별 관심 요청. 무단 노출 위험이 있으면 기능을 열지 않는다.
- **후순위/미결정:** AI 추천 보조, 현금 보상·리워드, QR 전용 가입, 주선자 동석, 정식 과금·브랜드 확정. 제품 미결정은 팀 합의 없이 확정 처리하지 않는다.

**Go/No-Go:** 실명·연락처를 수집하는 베타에 필수 동의·접근통제·삭제/신고 절차가 갖춰지지 않으면 제한적 사전등록으로 범위를 축소한다. 기혼 주선자가 실제로 지인을 초대하는지와 싱글 동의가 확보되는지 확인하지 않은 채 기능만 확대하지 않는다. 개인별 HW6 프로토타입은 팀 통합 제품의 구현·보안 완료를 의미하지 않는다.
