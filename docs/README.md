## 프로젝트 소개

뚜(TTU)는 기혼 주선자가 싱글 지인을 연결하는 소개 서비스다. 여러 소개의 연락과 정보 전달을 관리하기 번거로운 주선자, 그리고 본인이 동의한 범위에서 소개에 참여하고 싶은 싱글을 위해 기획했다.

기혼 주선자들이 협력해 소개를 제안하고, 양쪽 싱글의 소개 수락·정보 공유 동의와 실제 연결 여부를 구분한다. 주선자는 여러 소개의 진행 단계와 다음 행동을 한곳에서 관리한다. 지인 관계와 정보 공개 권한을 구분하며, 가입했다고 모든 지인에게 프로필이 공개되는 방식은 지향하지 않는다.

## 기본 이용 흐름

1. 기혼 주선자가 소개할 싱글 지인을 초대한다.
2. 싱글 본인이 참여 여부와 프로필 공개 범위·주선 권한을 선택한다.
3. 허용받은 주선자들이 협력해 후보와 소개 이유를 정하고 소개 제안을 보낸다.
4. 양쪽 싱글의 소개 수락과 정보 공유 동의를 각각 확인한 뒤 연락을 연결한다.
5. 주선자는 진행 상태와 다음 행동, 실제 연결 여부와 후속 기록을 관리한다.

## 현재 검증 범위

**초대부터 동의와 실제 연결까지의 소개 흐름**을 검증한다. 초대받은 싱글이 공개 범위를 이해하고 참여하는지, 주선자가 여러 소개의 진행 단계와 다음 행동을 파악하고 한 건을 끝까지 이어갈 수 있는지 확인한다. 기존 메신저로 소개할 때보다 어떤 수고가 줄어드는지도 살핀다. 소개 수락과 실제 연결, 만남은 나눠 기록한다.

현재는 기획과 기능 프로토타입을 바탕으로 초기 검증을 준비하는 단계다. 실제 수요와 운영 효과는 검증이 필요하다. AI는 주선 보조로 두며 **QR 초대, 주선자 동석, 리워드·과금 방식** 등 세부 운영 방식은 팀의 결정 상태를 따른다. 서비스 이름도 가칭이다.
