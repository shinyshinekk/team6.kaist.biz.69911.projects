# UI/UX 개선안 — 소개 부탁 보내기 (F18)

**관련 기능:** WhyTree ① 소개 부탁 보내기 / PRD v0.5 의 스타일 넛지(F18)
**개선 목적:** 
1. 싱글 사용자가 '포기 못 할 기준 2개'를 정하는 의도를 직관적으로 인지하도록 가이드 강화
2. 주선자의 판단 부담을 낮추되, 싱글이 정성껏 고른 선호 조건(`우선 고려`)이 버려지지 않도록 주선자 카드 UX 개선

---

## 1. 싱글 조건 선택 화면 UI 개선

### 1.1 세그먼트 버튼 라벨 변경 (`포기 못함` 세트)
기존의 단순 등급 표기(`필수 / 선호 / 상관없음`) 대신 사용자의 직관적인 선택을 돕는 단어 조합으로 변경합니다.

* **기존:** `필수` | `선호` | `상관없음`
* **개선:** **`포기 못함`** | **`우선 고려`** | **`타협 가능`**

### 1.2 상단 타이틀 & 카운터 강화
상단에 명확한 제한 안내 및 서브 타이틀을 배치하여 상한 제약(최대 2개)을 직관적으로 보여줍니다.

* **메인 타이틀:** **이런 사람을 소개해 주세요**
* **서브 타이틀:** 절대 포기할 수 없는 기준은 **딱 2가지**만 선택해 주세요.
* **우측 카운터:** `포기 못함 1/2` (또는 `1/2개 선택됨`)

### 1.3 하단 가이드 문구 개편 (주선자 노출 방식 안내 포함)
설명조의 철학적 문구를 제거하고, 주선자에게 어떻게 노출되는지 명확히 인지시켜 신중한 선택을 유도하는 넛지 문구로 교체합니다.

* **기존:** "필수는 두 개까지입니다. 무엇을 양보할지 고르는 일이 이 기능의 핵심입니다."
* **개선:** **💡 조건이 너무 까다로우면 주선자가 사람을 떠올리기 힘들어요. 주선자에게 먼저 보일 '포기 못 할 기준 2개'를 신중히 골라보세요.**

---

## 2. 주선자 수신 카드 UX 개선 (정보 계층화)

### 2.1 문제 정의
주선자 카드 전면에 '포기 못함' 2개만 보이면, 싱글이 설정한 '우선 고려' 조건이 무시되거나 싱글 입장에서 조건 설정의 의미가 퇴색될 위험이 있습니다.

### 2.2 해결 방안: 2단계 정보 노출 구조

1. **1단계 (요약 카탈로그 뷰 - 부탁함 목록):**
   * **노출 내용:** 싱글 프로필 기본 정보 + **`포기 못함` 조건 2개** + 자유 한마디(200자)
   * **목적:** 주선자가 리스트를 훑어볼 때 뇌 과부하 없이 빠르게 머릿속에서 지인을 떠올리도록 최소 정보만 전달 (PRD 핵심 리스크 방지)

2. **2단계 (상세 보기 뷰 - 탭/클릭 시 펼침):**
   * **노출 내용:** `포기 못함` 2개 강조 + **`우선 고려` 조건 태그 및 전체 조건 목록**
   * **목적:** 주선자가 "어? 이 조건에 맞는 지인 있는 것 같은데?" 하고 `확인`을 누르거나 상세 카드를 열었을 때, 싱글의 세부 취향(`우선 고려`)을 종합적으로 검토하여 디테일한 매칭 가능
