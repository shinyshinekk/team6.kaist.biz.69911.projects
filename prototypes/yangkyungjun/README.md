# 소개 부탁 보내기 (①) — 프로토타입

양경준 / HW6 / 2026-10-28
스펙: [`docs/specs/yangkyungjun-feature.md`](../../docs/specs/yangkyungjun-feature.md)
UI/UX 개선안: [`ui_ux.md`](./ui_ux.md) — 등급 라벨과 주선자 카드 2단계 노출은 이 문서가 출처다

## 무엇을 검증하는 프로토타입인가

화면 시연이 아니라 **부탁 객체의 스키마와 상태 기계**를 확정하려고 만들었다.
따라서 남는 물건은 `intro-request.js` 와 스펙 문서이고, `index.html` 은 그것이 실제로 돈다는 걸 눈으로 보여주는 장치다.

| 파일 | 역할 |
|---|---|
| `intro-request.js` | **상태 기계 + 검증 규칙 + 등급 라벨.** 순수 함수, 시간은 `now` 인자로 주입. 실제 앱으로 옮겨질 물건 |
| `intro-request.test.js` | checks 24개 (`node --test`) |
| `index.html` | 앱 한 장 — 마크업 · 스타일 · 화면 로직 전부. 규칙은 한 줄도 들어 있지 않다 |

상태 기계를 `index.html` 안에 합치지 않은 이유: 합치면 `node --test` 가 그 파일을 읽을 수 없다.
테스트가 붙을 수 있는 경계가 곧 실제 앱으로 옮겨질 경계다.

## 실행

**테스트**

```
cd prototypes/yangkyungjun
node --test
```

레포 루트에서 바로 돌리려면:

```
node --test "prototypes/yangkyungjun/*.test.js"
```

(`node --test prototypes/yangkyungjun` 처럼 디렉터리만 주면 Node 가 그 경로를 모듈로 읽으려다 실패한다. 경로 끝까지 적거나 위 두 형태를 쓴다.)

**화면** — `index.html` 을 더블클릭한다. 설치할 것도 서버도 없다.

> ⚠️ **인터넷이 필요하다.** Tailwind CSS 와 본문 서체(Nanum Myeongjo · Cormorant Garamond)를 CDN 에서 받는다.
> 오프라인에서 열면 **기능은 전부 그대로 돌지만 디자인이 벗겨진다.** 발표·제출 전에 연결을 확인할 것.

## 화면 보는 법

브랜드는 **뚜**. 한옥 어휘를 그대로 화면 구조에 썼다.

- **히어로** — 백라이트 창살. `소개 부탁 보내기` 를 누르면 대문으로 내려간다.
- **대문(大門)** — 싱글. 주선자 한 명을 고르고(선택하면 ✓ 와 `선택됨` 뱃지), 7개 항목에 `포기 못함 / 우선 고려 / 타협 가능` 을 매겨 보낸다. **`포기 못함` 은 2개까지.**
- **사랑채(舍廊)** — 주선자. 카드에는 **`포기 못함` 2개와 한마디만 먼저** 보인다(1단계). `조건 전체 보기` 로 펼치면 `우선 고려` 와 7개 항목 전체가 나온다(2단계). 그 뒤 `찾아볼게요`(확인) · `조금 뒤에`(보류) · `이번엔 어렵겠어요`(종료).
- **마당 — 시간**(화면 아래 고정). `+1일` / `+7일` 로 시계를 돌린다. 만료·쿨다운이 전부 시간 기반이라 이게 없으면 절반을 못 본다.

화면 폭이 좁아지면 두 칸이 세로로 쌓이고, 조건 행은 `항목 + 등급` 아래로 값 선택이 내려간다.

## 눈으로 확인할 것 (수동 checks)

| # | 해볼 것 | 보여야 하는 것 |
|---|---|---|
| **M1** | 사랑채에서 `이번엔 어렵겠어요` 클릭 | 대문 쪽이 즉시 **"이번엔 닫힘"**. 싱글에게는 거절인지 만료인지 **구분되지 않는다**(사랑채에만 "내가 종료했습니다"가 뜬다) |
| **M2** | 부탁을 보내고 아무것도 안 한 채 `+7일` | 만료되어 **남은 칸이 돌아온다**. 그리고 같은 주선자에게는 14일간 다시 못 보낸다 |
| **M3** | 세 번째 항목을 `포기 못함` 으로 찍어보기 | 막히고, **하나를 `우선 고려` 로 내려놓아야** 한다고 말해준다. 우측 카운터는 `포기 못함 2 / 2` |
| **M6** | 사랑채 카드를 그냥 보기 → `조건 전체 보기` 누르기 | 1단계에는 `포기 못함` 2개 + 한마디만. 펼치면 `우선 고려` 와 **7개 항목 전체**가 등급 라벨과 함께 나온다 |
| M4 | 사랑채에서 `조건 전체 보기` 를 누른 뒤 대문 쪽을 보기 | `고치기` 버튼이 사라진다. 펼침이 곧 열람이고, 주선자가 떠올려 본 수고를 지키기 위해서다 |
| M5 | 부탁을 3건 보내고 네 번째 시도 | 주선자 카드가 전부 잠기고 이유가 뜬다 |

## 주의

- 등급의 사용자 라벨은 `intro-request.js` 의 `GRADE_LABELS` **한 곳**에서만 온다. 내부 키(`must`/`prefer`/`any`)는 그대로다 — 저장된 데이터가 전부 이 키이고, 바꾸는 것은 사람이 읽는 말뿐이다.
- 카드의 펼침 상태는 저장하지 않는다. 남아야 하는 사실(**열어봤다**)은 부탁의 `readAt` 에 이미 박혀 있다.
- 저장은 `localStorage` 다. `처음부터` 버튼(**두 번 클릭** — 첫 클릭은 확인)으로 지운다.
- 주선자 3명(김선영·박지훈·이수진)과 싱글 1명은 **가짜 시드 데이터**다.
- 알림은 없다. P0-Beta 로는 필수지만 프로토타입에는 불필요해서 뺐다(스펙 §4).
