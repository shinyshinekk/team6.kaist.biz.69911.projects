# TTU — 한 건을 끝내는 소개 보드

현재 HW6 제출 후보. 이전 SAI 카운터·싱글 중심 검토 자료와 구분한다. 외부 패키지·API 키·유료 인프라 없이 Node.js 18 이상으로 실행한다.

```powershell
node --test prototypes/gyunggoo/tests/core.test.mjs prototypes/gyunggoo/tests/integration.test.mjs prototypes/gyunggoo/tests/ui.test.mjs
node prototypes/gyunggoo/server.mjs 8767
```

Chrome에서 http://127.0.0.1:8767 을 연다. `.data/board.local.json`에 합성 기록이 저장된다. 파일을 직접 여는 방식은 서버 상태·관계 검사를 실행하지 않는다. 서버는 127.0.0.1에만 바인딩하고 HTML/CSS/JS 등 허용한 파일만 제공한다.

모든 후보·actor·동의·연결 확인은 합성이다. 역할 선택은 실제 인증이 아니며 header를 바꾸면 해당 합성 actor로 시험할 수 있다. 실제 인증·관계 DB·TTU 서비스 보안이나 실제 사용 성과의 증거로 쓰지 않는다. 실제 개인정보 입력 필드·연락처·외부 발송·AI 모델은 없다.

명세: [gyunggoo-introduction-board.md](../../docs/specs/gyunggoo-introduction-board.md). WhyTree: [gyunggoo.md](../../docs/whytree/gyunggoo.md).
PPTX/PDF와 성찰 초안·최종 본인 체크는 작업 패키지에 함께 제공한다. 실제 사용자 면담·본인 화면 검사를 에이전트 작업으로 대신 완료했다고 쓰지 않는다.

## 검사 기록 — 2026-10-29

사용자가 제품·문제와 검사 방향을 정하고 AI에 실행과 결과 반영을 지시했다. PPTX/MD의 10개 노드·9개 연결은 사용자가 직접 확인했고 수정 요청은 없었다. 아래는 AI가 수행한 검사 결과다. 사용자의 화면 직접 클릭 기록이나 새 결과에 대한 최종 판정으로 바꾸어 쓰지 않는다.

위 실행 명령의 3개 테스트 파일은 10월 29일 16시 정상 로컬 실행에서 **23/23 통과**했다. 이 중 UI 검사 5개는 실제 app.mjs를 최소 DOM·지연 응답 모형에서 실행한 자동 검사이며 Chrome 클릭 검사가 아니다. 최초 샌드박스 실행은 임시 파일 rename의 EPERM과 로컬 연결 EACCES 영향으로 19/23이었고, 코드 변경 없이 정상 권한 경로에서 전부 통과했다. 추가 저장 보존 검사는 합성 임시 파일만 사용했고 기존 데모 파일의 해시가 유지됐다.

현재 화면 제어가 중단되어 10월 29일 새 Chrome 클릭 검사는 하지 않았다. 새로고침·파일 재열기·별도 프로세스의 보존 검사를 실제 브라우저와 서버 프로세스를 함께 재시작한 검사로 합쳐 쓰지 않는다. 기존 실제 UI 증거와 이번 자동 검사를 구분하며, 사용자 최종 판정은 결과 보고 뒤 실제 응답으로 남긴다. AI 실행 방식이 과제의 ‘본인이 직접 검사’ 요건으로 인정되는지는 확인되지 않았다.
