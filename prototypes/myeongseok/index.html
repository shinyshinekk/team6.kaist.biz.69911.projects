뚜 TTU
HW6 · F18 개인 실험

연애는 너희가,
소개는 우리가.

원하는 스타일을 선택하고, 내가 지정한 기혼 주선자 한 명에게만 조용히 요청하세요.

실제 서비스가 아닙니다. 가상 싱글 1명과 가상 주선자 2명이 한 브라우저에서 역할을 바꾸며 작동하는 시연입니다. 실제 사람의 정보, 개인정보, 연락처를 입력하지 마세요. 회원 인증·서버 권한검사·AI 추천·외부 메시지 전송은 없습니다.

내가 원하는 소개, 먼저 말할 수 있어요.

공개 단계는 L0 비공개, 발견 후보는 0명으로 고정한 테스트입니다. 요청을 보내도 공개 범위나 소개·연락처 동의는 바뀌지 않습니다.

원하는 스타일 알려주기

0/120자 · 연락처·링크·실명·타인의 개인정보 등 입력 금지

보내기 전에 확인

스타일과 주선자를 선택한 뒤 제출해 보세요.

내 요청 상태

아직 제출된 요청이 없습니다.

주선자 연결 관리 테스트용

연결을 해제하면 해당 주선자의 진행 중 요청이 종료되고 원문을 새로 열람할 수 없게 됩니다. 다른 주선자와의 연결은 유지됩니다.

가상 주선자 수신함

서로의 수신함은 분리되어 있으며 상대 싱글 또는 다른 주선자에게 요청을 자동 전달하지 않습니다.

이 주선자에게 도착한 요청이 없습니다.

해당 수신함의 종료 기록

키워드와 자유 설명은 종료 시 제거합니다. 종료 상태와 최소 시각 기록만 남습니다. 주선자의 내부 결과는 싱글에게 노출되지 않습니다.

종료된 요청이 없습니다.

시연 시간

실제 시계가 아니라 변경 가능한 가상 시각입니다. 자동 만료와 24시간 재요청 제한을 직접 검증하세요.

처음 제출 시각과 검토 시작 시각을 기준으로 만료를 계산합니다.

결정된 운영 규칙

  1. 진행 중 요청은 주선자별 최대 1개
  2. 키워드 1~3개, 설명 120자 선택
  3. 수정하려면 철회 후 새 요청
  4. 최초 검토 시작 시 만료 시계 한 번 재설정
  5. 진전 없이 7일이면 기한 만료
  6. 동일 주선자는 제출 후 24시간 재요청 제한
  7. 철회·연결 해제 즉시 원문 신규 조회 차단
  8. 외부 문자·메일 없이 앱 수신함 표시만

검증용 카운터

넛지 접수는 소개 제안·양측 수락·소개 완료와 다릅니다.
